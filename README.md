# CRM Engine

PipeDrive-style CRM starter monorepo.

## Included

- Next.js sales dashboard
- API health and CRM endpoints
- Prisma schema foundation
- Shared CRM types and utilities
- Dockerized Postgres and Redis starter

## Run locally

```bash
npm install
npm run dev
```

The frontend is available at http://localhost:3000 and the API at http://localhost:4000/api.
